## Reuse

The original study notes in `notes/` are dedicated to the public domain under [CC0 1.0](CC0-1.0.txt). See the license for its full terms. This statement applies only to those original notes. It does not grant rights in third-party material.

## Content checks

A local pre-commit hook permits only the exact files listed in `publication-manifest.json` with the listed SHA-256 hashes. It blocks unlisted files, binary content, attachments, credentials matching its checks, and changed content until the manifest is deliberately reviewed and regenerated. File screening is a safeguard, not a legal determination.

To verify the staged publication, run `node scripts/check-publication.mts`.
